如何將機器人從SOLIDWRKS匯入WEBOTS且能模擬我所需要的動作。

  • 按下 URDF 匯出工具

  • 設定項目包含：

    • 主體

    • 每個 Link 構成的零件

    • 各個 Joint（旋轉軸、移動軸）

  • 每個關節需：

    • 設定 座標系

    • 設定 軸方向

選擇此關節所包含的零件

(要注意主配合和子配合要搭配好)

完成後按「預覽與匯出」

將 URDF → PROTO:"C:\Users\SSAL\AppData\Local\Programs\Python\Python314\python.exe" -m urdf2webots.importer --input "C:\Duck\urdf\Duck.urdf" --output "C:\Duck\Duck.proto"

第三階段：設定 Webots 專案。Webots → File → New Project Directory選擇proto所在的資料夾

如何實作一套 5-bar Linkage Plotter 與 Openduck mini？

5-bar linkage 是一種平面雙臂連桿機構，常用於精確定位末端執行器。

基本構造

  • 基座 (Base): 固定兩個旋轉伺服的座標點。

  • 兩個旋轉臂 (Crank)

  • 兩個連桿 (Coupler)

  • 末端執行器 (End-effector / Pen holder)

進入 3D 列印與實體組裝後，我深刻體會到「能製作出來」才算真正完成設計。列印翹曲、支撐配置、列印方向、孔位公差與鎖點強度等問題，都在實際裝配時一一浮現。許多零件在尺寸上看似正確，實際組裝卻會產生卡滯、鬆動或干涉，迫使我回頭檢討公差配置、結構設計與裝配順序。這個反覆修正的過程，讓我學會以更務實的角度檢視設計，而不是只停留在理論或外觀層面。

最後，將完成的模型匯入 Webots 進行動態模擬與 Python 控制。透過模擬，我能快速觀察運動軌跡、碰撞情況，並即時調整參數，小幅修改對整體運動所造成的影響。從 URDF／PROTO 的轉換、關節設定到控制程式除錯，我逐步將 CAD、機構設計、運動學與控制整合在同一流程中，建立完整的系統觀念。

整體而言，這堂課帶給我最大的收穫，不只是技術能力的提升，而是工程設計思維的建立：先拆解問題、驗證假設，再透過反覆測試與優化逐步改善系統。這樣的訓練，讓我在面對未來專題或實務應用時，即使系統複雜，也能有條理地將想法一步步實現。
